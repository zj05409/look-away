# Design system

| Token | Value | Use |
|-------|-------|-----|
| `LookAwayBrand.accent` | `rgb(1.0, 0.42, 0.78)` | Status chips, glass tints, hold progress |
| `LookAwayBrand.accentSoft` | softer pink | Highlights |
| `LookAwayGlass.panelCornerRadius` | 22 | Menu panel outer shell |
| `LookAwayGlass.controlCornerRadius` | 10 | Buttons / control fills |
| `LookAwayGlass.insetCornerRadius` | 8 | Nested inset controls (if any) |
| `MenuPanelMetrics.spacing` | 6 | Vertical/horizontal gaps in menu |
| `LookAwayMetrics.holdConfirmDuration` | 11s | Skip / restart hold |

Typography: SF Rounded via `.system(..., design: .rounded)`.
